## 目标与边界

- 建立两套流程共用的结构化 `ProgressEvent`，由主机真实动作与 Runtime 工具事件产生；
- 展示“检索知识、分析截图、定位页面、阅读代码、查询数据库、制定方案、修改、验证、沉淀能力”等阶段；
- 模型输出只可作为经过裁剪的辅助详情，不直接展示推理过程、完整 SQL、命令、密钥或原始工具参数；
- 持久任务状态与瞬时执行进度分层显示，完成后的 durable 状态保持不变；
- 进度切换采用轻量淡出/淡入和呼吸指示，不阻塞任务线程；
- 延续白银浅色玻璃界面，`#667eea` 仅用于进度指示与少量交互高亮，不改变整体主题；

- 开发和异常处理应用接口均可接收可选进度回调，未传回调时保持兼容；

- UI 后台队列可连续接收进度，不会误判任务已经结束；
- 相同阶段合并，快速阶段保证最短可见时间，文本平滑切换；
- 进度回调异常不会使 Agent 任务失败；
