# ACE-CORE-055 审批前校验与方案面板

状态：done（2026-11-13，0.25.1）。
授权：用户确认先给方案后执行，范围为审批误拦截修复、校验前移、历史方案重新核对和可拖动折叠方案区。
根因：Runtime将工作区外Read路径脱敏为OUTSIDE_WORKSPACE标记，审批将标记当作实际相对文件，缺指纹导致永久阻塞。界面禁用按钮只显示笼统范围提示。
实现：候选方案先做宿主校验，只读轮可补查一次，仍有缺口则暂停并保存具体原因。有效方案待用户批准，执行前继续核对漂移。
布局：桌面对话与方案可拖动调宽、折叠、恢复阅读位置，窄窗口合理切换；历史受阻方案显式只读重新核对。
验收：真实标记回归、有效方案直接审批、缺口补查有界、实施轮不重放、旧快照重新审阅、拖动折叠/缩放/多窗口。
保留：原incident/engine.py用户注释、私有知识及ERROR_LOG不纳入提交。
验证：非桌面全量559项通过（178.88秒），桌面55项通过（24.76秒），合计614项。Ruff、compileall和diff检查通过。仅现有Starlette/httpx弃用警告。
