# ACE-API-034：远程交互闭环

- 状态：done，2026-09-30；版本 0.11.0。
- 授权：用户要求按既定第二步推进，止于常驻部署之前。
- 范围：手动进入异常处理、待审批方案与版本绑定、批准/拒绝、持久化进度事件与轮询、完整回归和文档。
- 不变量：诊断只读；没有显式批准不得修改代码；批准只能作用于用户看到的当前方案；排队与执行前均验证版本；中断不能自动重放写入。
- 实现：接口层新增手动修复、批准/拒绝、版本与方案指纹双校验；API 事件单独落盘并按游标读取。
- 恢复：Worker 检查已持久化的领域命令回执或已保存的修复方案，只补齐队列完成状态；
  没有领域结果的操作仍需显式恢复。同诊断轮次重复请求复用任务，所有请求键都保留幂等约束。
- 验收：诊断到修复方案、批准修改及验证闭环；旧批准 409；重复请求仅执行一次；权限隔离；进程重启后方案和事件可查；不暴露模型内部原始事件或敏感数据。
- 已验证：315 项非 live 测试通过；Ruff、compileall、diff check 通过。真实 HTTP 进程提交任务
  返回 202，事件在 API 重启后可续读，新路由显示于 OpenAPI；安装后的 CLI 入口可运行。
- 发布：按 RELEASING.md 形成单一提交并推送主分支；提交 ID 见 Git 日志。
- 限制：真实模型/业务数据库联调由用户执行；本轮不做 Windows 服务、自动启动、外部 HTTPS/钉钉部署。用户 `docs/ERROR_LOG.md` 不改、不提交。
