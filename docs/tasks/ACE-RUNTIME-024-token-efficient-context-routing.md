# ACE-RUNTIME-024：低 Token 上下文路由

## 1. 目标

在不降低 ACE 的需求澄清、页面定位、源码调查、SQL Server 只读取证和异常结论能力的前提下，
减少简单续聊和深度多轮调查中的重复上下文与无效模型往返。

## 2. 实现

- 完成后的无附件异常追问先使用独立、无工具、无历史的紧凑路由；
- 已有证据足以回答时直接完成并追加原能力文档，需要新事实时升级原完整 Runtime 会话；
- 路由只携带页面、结论、诊断、动作、置信度和最多十条查询摘要；
- 开发与异常流程共用紧凑数据库上下文，不再每轮注入完整 schema；
- 模型需要结构时从源码收敛目标，再发起有界只读元数据查询；
- 已知且可共同解释的小型 SQL 优先在同一个结构化批次执行；
- 完整调查 Prompt 保持稳定前缀，动态阶段内容移到尾部；
- Claude CLI 支持通过 `--tools ""` 显式创建无工具模型会话。

## 3. 验收

- 简单续聊实测 1 次 Runtime、0 次 SQL、2,716 输入与 543 输出 Token；
- 完整异常实测仍完成页面、源码、数据库和结论闭环；
- 完整流程总 Token（含缓存）较基线下降约 54.6%，直接输入输出下降约 19%；
- 查询批次从 4 降到 2，模型回合从 19 降到 11；
- 单元测试覆盖直接回答、深度升级、页面复用、空工具 CLI 和两流程按需 schema；
- 完整非 live 测试、Ruff、compileall 和 diff 检查通过；
- 发布 `v0.7.11` 并推送 GitHub 一次。
