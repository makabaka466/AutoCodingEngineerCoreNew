# ACE-INCIDENT-023：继续对话附件重封装与最终结论

## 1. 问题

- 异常会话继续对话时，有效截图可能因记录大小与发送时大小不同而在模型启动前失败；
- 完成决策虽有结构化诊断和建议，但最终 Assistant 正文不保证清楚展示原因与解决方法；
- 桌面后台异常只显示弹窗，没有进入现有本地日志。

## 2. 实现

- 发送前重新验证 ACE 隔离目录中的 PNG，并刷新有效图片的实际大小；
- 保留 Engine 严格大小校验，拒绝损坏、超限和目录外附件；
- 完成结果统一渲染“结论 / 为什么出现这个异常 / 解决方法 / 结论置信度”；
- Prompt 要求模型标注结论确定性、因果链和具体动作；
- 历史记录缺少动作时使用保守补证据提示，不破坏兼容性；
- 桌面后台和附件准备错误写入本地应用日志。

## 3. 验收

- 使用现场有效 PNG 和错误旧大小元数据复现，重封装后得到真实 35003 字节；
- 有效变化图片通过，损坏替换内容被拒绝；
- 异常 Outcome 的最终正文包含四个固定部分；
- 完整非 live 测试、Ruff、compileall 和 Git 差异检查通过；
- 发布 v0.7.10 并推送 GitHub。
