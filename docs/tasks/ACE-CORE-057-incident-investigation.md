# ACE-CORE-057 异常调查与开发交接

版本 0.27.0。现场反馈涉及跨项目内目录搜索、一次粘贴多张截图、菜单查询顺序、模型调查小结和诊断转开发卡顿。

- 不同截图可以对应同一流程的不同页面。新任务按消息内图号审计真实 Read 返回，关联页面混入主要页面时依据图号和有效源码指纹处理。
- 有页面线索和默认目录配置时由宿主先查目录。源码路径、已知命名空间和后台入口沿用直接调查。项目根目录 Grep 可以使用特征词，继续限制返回量和每轮调用次数。
- 每次主要工作流 Runtime 调用随同原响应提交检查、发现与下一步，旧会话仍可读取。诊断正文保留简洁方案，证据与 SQL 草案可在详情查看。
- 桌面交接复用当前显示的诊断，在后台重新检查版本、初始化开发应用并准备审批。慢操作和主线程卡顿有独立日志。没有内存溢出的现场证据。
- 回归覆盖剪贴板原子导入、两个同名截图、跨页错配、菜单离线及停止、审批交接。隔离 Tk 主循环连续停顿后只记录一次栈采样；真实业务库和远程模型未参与回归。

验证完成：645 项非 live 测试通过，Ruff、compileall 和 diff 检查通过；仅有已有的 Starlette 弃用提示。
