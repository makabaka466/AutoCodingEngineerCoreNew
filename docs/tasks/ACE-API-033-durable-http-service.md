# ACE-API-033：独立 HTTP 接口与可靠执行

- 状态：done，2026-09-30；版本 0.10.0。
- 授权：用户要求实施第一步；接口集中到新的位置，通过应用服务调用，钉钉接入留到后续。
- 范围：独立 autocoding_api 包；Token 身份/项目权限；创建、追加消息、任务/操作查询；持久化队列、幂等、单 Worker、显式只读恢复；调用文档与示例。
- 不变量：现有流程、证据规则、模型、提示词、预算、审批均不改变；普通消息不授权修改；HTTP 不运行模型和恢复扫描。
- 可靠性：接受操作前落盘；创建任务预分配 ID；领取后中断不重放；版本在提交和执行前检查；进程锁先于应用构建和恢复。
- 验收：身份/项目/任务隔离、重试幂等、落盘重启、排队保留、中断停止重放、版本冲突、两领域真实门面集成、原有完整回归。
- 已验证：304 项非 live 测试通过；Ruff、compileall、diff check 通过；独立安装入口可用。
- HTTP 实际进程重启烟测：202 接收创建任务，重启 API 后原 job_id 仍可查询 queued。
- 结果：开发/异常真实门面脚本决策、权限隔离、并发幂等、Windows 跨进程锁、崩溃恢复、
  版本前后双校验、普通消息不授予修改权限均已覆盖。
- 发布：按 RELEASING.md 形成单一提交推送主分支；提交 ID 以 Git 日志为准。
- 限制：未部署为 Windows 系统服务；未连接钉钉；真实模型和业务数据库验收由用户执行。用户 docs/ERROR_LOG.md 不改、不提交。
