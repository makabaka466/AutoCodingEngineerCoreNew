## 当前状态与关键发现

- 已确认视觉目标：大圆角浅色玻璃面、低对比柔和阴影、Apple Blue 主操作、宽松留白；
- Tkinter 不支持浏览器级 `backdrop-filter` 和逐层 RGBA 模糊，本次用原生 Canvas 的圆角分层、
  内高光、浅色阴影与材质色近似，避免引入第二套 Web 前端；
- 视觉稿右侧统计为示意数据，产品实现改为读取当前流程的持久化 Session 及本机配置状态；
- 本次不改变状态机、Event/Recovery、权限或 SQL 自动查询边界。
- 已完成主界面、系统设置令牌、真实概览、响应式布局、占位文案和自动高度修复；
- 同视口设计 QA 已完成两轮修正，最终无 P0/P1/P2，原生 Tk 毛玻璃和历史任务行距记为 P3。
