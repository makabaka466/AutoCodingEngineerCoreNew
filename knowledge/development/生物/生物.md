# 指纹 MES 开发基础知识

> 本文保存跨页面、可长期复用的开发知识。具体页面的临时状态和单次问题记录应进入任务能力
> 文档，不持续追加到本文。所有代码位置均使用当前工作区相对路径；修改前先核对仓库根目录和
> `git status --short`。

## 项目概况

- 主解决方案为 `QTMES.sln`，主体技术是 .NET Framework、WinForms、EF6。
- `MESClient/` 是主要客户端，入口和 Autofac 注册位于 `MESClient/Program.cs`。
- `QTMES.Model/Entities/` 保存 EF 实体；`QTMES.Application.Interface/` 与
  `QTMES.Application/` 分别保存服务接口和实现。
- `QTMES.Core/` 定义 Repository、UnitOfWork 等抽象，`QTMES.Infrastructure/` 提供 EF6 实现；
  DbContext 位于 `QTMES.Infrastructure/Data/EntityFramework/EFDbContext.cs`。
- 项目还包含旧 Web、Web API、报表和独立 API 子项目。只检查与当前需求直接相关的调用链，
  不因项目较大而默认全仓扫描。
- 项目历史命名中存在 `Serivce` 等拼写，新增代码优先保持所属模块的既有风格，避免无关重命名。

典型调用链：

```text
WinForms 页面
  → Application.Interface 服务接口
  → Application 服务实现
  → Repository / UnitOfWork
  → EFDbContext
  → 数据库
```

## 页面名称定位代码

用户只提供页面名称时，优先通过共享只读数据库查询菜单映射：

```sql
SELECT NAME, URL
FROM Menu
WHERE NAME LIKE :page_name
```

- `page_name` 使用“页面名称 + `%`”，必须参数化，不拼接用户输入。
- `URL` 只是页面相对位置线索；仍需在当前工作区验证文件、窗体、路由、事件入口和调用链。
- 无结果或结果不唯一时，向用户询问页面标题、操作入口或相对路径，不得猜测文件位置。
- 实际 schema 与示例不一致时，以只读 schema 为准，不猜测字段，也不改用写操作。

## 通用开发规则

### WinForms

- 固定布局修改 `.Designer.cs`，事件和业务逻辑修改对应 `.cs`。
- 新增控件同时核对字段声明、`InitializeComponent` 初始化、事件绑定、锚定、滚动和项目包含关系。
- 源文件编码较敏感，避免批量格式化、整体重编码或无关资源文件变更。
- 服务无法解析时，优先检查 `MESClient/Program.cs` 中的 Autofac 注册。

### EF6 与业务写入

- 新增实体时核对数据注解、`DbSet` 和 `OnModelCreating` 映射。
- 常规新增链路通常为 `Repository.Insert(...)` 后 `UnitOfWork.Commit()`；提交位置必须服从现有
  事务边界，不能只根据方法名推断数据已经落库。
- 连接串、账号和密码属于环境配置，不得写入源码、能力文档、日志或提交记录。

### 外部接口与日志

- 恢复或新增真实外部调用前，必须确认接口地址、认证、请求体、超时和返回格式，并先在测试
  环境联调。遇到提交无外部结果时，先检查是否存在测试返回值、注释调用或模拟实现。
- 当前良率上传相关代码曾存在真实调用被注释、返回 `testUpLoad` 的测试状态；只有任务确实涉及
  该功能时才核对现状，不把这条历史信息套用到其他页面。
- 写日志前核对数据库字段长度和实体映射。`YIELDUPLOAD_LOG` 已知 `CONTENT` 为
  `nvarchar(1000)`，`RESULT`、`MUSER` 为 `nvarchar(50)`；需要完整报文时应先确认数据库设计，
  不得静默截断或假设日志保存了完整请求。
- 日志应保留定位问题所需的业务标识、结果和时间，禁止记录连接凭据、Token 或其他秘密。

## 修改与验证

- 先阅读目标文件及其直接依赖，给出“当前状态、拟修改内容、目标结果、影响和验证方案”，经用户
  确认后再实施。
- UI 修改后至少构建 `MESClient/MESZWClient.csproj`，并在可运行环境检查布局、事件和交互。
- 推荐使用相对路径构建：

```powershell
MSBuild.exe .\MESClient\MESZWClient.csproj /t:Build /p:Configuration=Debug /m:1 /v:q
```

- 构建警告可能来自历史依赖；先区分是否由本次修改引入，不顺手扩大任务范围。
- 只暂存本次实际修改的源文件，不批量清理未知 `bin/`、`obj/` 或用户变更，不使用
  `git reset --hard`。
