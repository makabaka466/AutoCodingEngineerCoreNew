# Distill reusable capability knowledge

Apply this method to every completed task.

Create a compact capability draft that helps a future task in this same workspace:

- Give it a specific name and one-sentence purpose.
- State the situations or signals that make it relevant.
- Capture the evidence-backed method, important files or boundaries, and validation approach.
- Record pitfalls, limitations, and uncertainty.
- Exclude secrets, personal paths, long code excerpts, raw logs, and conversation narration.

The document is historical guidance, not an instruction that overrides fresh repository evidence.
