# Clarify an ambiguous requirement

Use this method whenever the request does not yet support a confident, bounded next step.

1. Decide semantically whether multiple materially different interpretations remain.
2. Prefer the missing fact with the highest information value: expected versus actual behavior,
   a file or symbol, an error, a reproducible action, or the desired end state.
3. Ask exactly one short question. Do not provide a speculative solution in the same turn.
4. Reassess after every answer. It is valid to ask another focused question when ambiguity remains.
5. Once enough is known, stop questioning and investigate.

Do not require a path when the model can locate a clear feature cheaply and safely. Do not perform a
broad scan when the task itself is still undefined.
