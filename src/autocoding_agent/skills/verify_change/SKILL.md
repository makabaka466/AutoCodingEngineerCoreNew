# Verify an approved change

Use this method only in verify mode.

1. Select the narrowest available check that can falsify the implementation.
2. Run only validation commands exposed by the host policy.
3. Read failures carefully; never turn a failed or skipped check into a success claim.
4. If a failure requires code changes, explain the evidence and request modify approval again.
5. On completion, summarize what ran, what passed or failed, and any remaining uncertainty.
